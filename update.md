# RoithiUI v2.0.0-Beta Release Notes

### 🌟 New Modules & Major Highlights

* **Cooldown Manager (CDM)**:
  New module! Custom cooldown bars with multi-row 2D grids, icons per row controls, and complete Blizzard CDM restyling.

* **Minimap & Addon Bar**:
  New module! Modern restyled minimap with coordinate overlays, movable Addon Compartment bar, and customizable expansion buttons.

* **Objectives Tracker**:
  New module! Clean restyled objective tracker with collapsible quests, custom status bars, and high-contrast readability.

* **Totem Bar & Swing Timer (Only in Forever)**:
  New modules! Dedicated combat-safe Totem Bar with Blizzard totem destroy integration, and smooth dual-wield Swing Timer.

* **Chat & Micro Menu**:
  New module! Sleek restyled chat with decoupled tab docking, live font scaling, and native Edit Mode layout persistence.

* **Bags & Inventory**:
  New module! Complete overhaul with category filters, smart retention timers, item level/count displays and Edit Mode support.

* **Actionbars**:
  New module! Unified 2D grid positioning, clickthrough toggles, and override actionbar safety.

* **UnitFrames & Castbars**:
  Full Midnight 12.1.5 combat secrecy compatibility, smooth Death Knight rune sorting, added PvP timer, and pure durationObj castbars.

* **Profile Manager**:
  Updated Profile Manager to create smaller profiles to share.
